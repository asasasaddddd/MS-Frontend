# 总待办与弹窗标题栏间距设计

## 目标

修复总待办“我的待办”页签贴住卡片左边框，以及自定义弹窗标题栏的默认关闭按钮与业务操作按钮重叠的问题。

## 根因

- `WorkspaceTodoView.vue` 将流程任务卡片的 `ant-card-body` 内边距设为 `0`，筛选区和任务列表各自补了 `18px`，但页签导航没有补齐同一间距。
- 部分首检和周检弹窗在自定义标题栏中已经提供“取消”“返回”或“关闭”操作，同时仍启用了 Ant Design Vue 默认关闭按钮。默认按钮使用右上角绝对定位，会覆盖标题栏右侧业务按钮。

## 设计

1. 仅为总待办的 `.workspace-task-tabs .ant-tabs-nav` 增加 `0 18px` 内边距，使页签与卡片标题、筛选区和任务列表对齐。
2. 对标题栏已经包含明确关闭操作的弹窗显式设置 `:closable="false"`。保留原有 `@cancel` 回调和业务按钮事件，不改变提交流程。
3. 普通信息查看、预览和选择弹窗继续保留默认关闭按钮。
4. 用合同测试固定这两个布局约束，并在桌面与窄屏浏览器中验证。

## 非目标

- 不移动操作按钮到弹窗页脚。
- 不修改业务字段、接口调用、流程节点或关闭回调。
- 不添加全局覆盖所有弹窗的 CSS 规则。

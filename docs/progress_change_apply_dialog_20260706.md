- 按用户提供的 7 张截图复刻管理员申请状态变更弹窗：
  - `检定周期调整申请`：当前周期提示、调整后周期、调整原因、申请日期、附件。
  - `管理类别调整申请`：当前类别提示、调整后管理类别、申请日期、附件。

  - `设备封存申请`：封存原因、申请日期、附件。
  - `设备启用申请`：启用原因、申请时间、附件。
  - `设备转移申请`：接收单位、转移原因、申请日期、附件。
  - `用前检定申请`：检定原因、申请日期、附件。

# 侧边栏多角色重复菜单修复（2026-07-08）

## 问题
- 员工 `U03016119` 配置全部角色后，侧边栏出现多条重复菜单：
  - 多个“周检”
  - 多个“首检”
  - 多个“C类物资抽检”
  - 多个“状态变更”
- 原因是这些页面按角色拆了不同路由，但侧边栏直接展示了当前人员拥有的全部角色入口。

## 根因
- `AppShell` 使用 `session.user.roles` 生成侧边栏。
- `useNavSections` 对每个角色可访问的页面逐条展示，没有按业务模块去重。
- 一个全权限人员同时拥有管理员、检定员、确认员、供应商等角色，因此同一个业务模块被重复显示。

## 修复
- 在 `useNavSections` 中按 `module + title` 进行展示去重。
- 同一业务模块只显示一个菜单项。
- 如果当前操作角色有对应路由，优先显示当前操作角色对应的路由。
- 切换页头角色时，如果当前页面存在同业务模块的角色路由，则自动跳转到新角色对应页面。
- 路由守卫仍按人员拥有的全部角色放行，不影响直接访问和业务权限。

## 涉及文件
- `src/composables/useNavSections.ts`
- `src/components/AppShell.vue`

## 验证
- `npm run typecheck`：通过。
- `npm run build`：通过。
